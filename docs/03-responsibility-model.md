# 03: Responsibility model

Every feature in every plan is assigned to exactly one of three layers. That makes scope visible and stops scope creep.

| Layer | When | Principle | Typical features |
|---|---|---|---|
| **A. Sales / instant provisioning** | At purchase, automatically | Technical infrastructure that needs no decisions | Sub-account, snapshot import, core CRM, base workflows and funnels, calendar, two-way SMS and email |
| **B. Onboarding call** | Within the first week, with the client | Needs the client's input or strategy | Pipeline stage refinement, branding, template personalisation, social planner, reputation set-up, community and membership structure, AI agent tone |
| **C. Specialist build team** | Scheduled, scoped | High complexity or custom | Advanced automations, API integrations, custom reporting, complex triggers, AI configuration beyond defaults, payment and affiliate logic |
